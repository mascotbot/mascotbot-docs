# Mascotbot React SDK

`@mascotbot-sdk/lipsync-react` is the React layer of the Mascotbot avatar SDK.
It gives you a provider, a few hooks, and a thin set of Rive components.
Speech goes in; the avatar speaks in real time.

This page is the map. Each area links to its dedicated guide.

## Install

```ini .npmrc
@mascotbot-sdk:registry=https://npm.mascot.bot/
//npm.mascot.bot/:_authToken=mascot_xxx
```

<CodeGroup>

```bash pnpm
pnpm add @mascotbot-sdk/lipsync-react
pnpm add @rive-app/react-webgl2 @rive-app/webgl2
```

```bash npm
npm i @mascotbot-sdk/lipsync-react
npm i @rive-app/react-webgl2 @rive-app/webgl2
```

```bash yarn
yarn add @mascotbot-sdk/lipsync-react
yarn add @rive-app/react-webgl2 @rive-app/webgl2
```

</CodeGroup>

`@rive-app/react-webgl2` + `@rive-app/webgl2` are optional peer dependencies of
the `/rive` subpath — install them only when you render an avatar. Full
registry and key setup is in [Installation](/installation).

## The two subpaths

| Import | Provides |
|---|---|
| `@mascotbot-sdk/lipsync-react` | `LipsyncProvider`, `useLipsync`, `useProcessAudio` — the audio pipeline. |
| `@mascotbot-sdk/lipsync-react/rive` | `MascotProvider`, `MascotClient`, `MascotRive`, `useMascotRive`, `useMascotInputs`, `useMascotPlayback`, `useLipsyncStream` — the Rive layer. |

## Composition

`LipsyncProvider` owns the licensed inference client. `MascotProvider` +
`MascotClient` own a Rive avatar. They are siblings — nest them once, near the
root.

```tsx
"use client";
import { LipsyncProvider } from "@mascotbot-sdk/lipsync-react";
import { MascotProvider, MascotClient, MascotRive, Fit, Alignment } from "@mascotbot-sdk/lipsync-react/rive";

export default function App() {
  return (
    <LipsyncProvider apiKey="mascot_pub_…">
      <MascotProvider>
        <MascotClient src="/mascot-fox.riv" layout={{ fit: Fit.Contain, alignment: Alignment.Center }}>
          <MascotRive />
          {/* your speaking components live here */}
        </MascotClient>
      </MascotProvider>
    </LipsyncProvider>
  );
}
```

| Component | Purpose |
|---|---|
| `<LipsyncProvider>` | Initializes one `MascotLipsyncClient`. Props extend the [client config](/installation#4-configure-the-client). |
| `<MascotProvider>` | Top-level Rive context; sibling to `<LipsyncProvider>`. |
| `<MascotClient src=… \| rive=…>` | Loads Rive and exposes its inputs via context. Pass a `.riv` URL **or** a pre-loaded Rive instance. |
| `<MascotRive>` | Renders the canvas. Children override the default render (use them for your own loading state). |

<Tip>
`<MascotClient>` accepts a pre-loaded `rive` instance you constructed
yourself. The SDK only writes the mouth, `is_speaking`, and `stress` —
everything else stays yours. See [Rive co-existence](/concepts/rive-coexistence).
</Tip>

## WebGL2 rendering

The Rive avatar renders through `@rive-app/*-webgl2`: hardware-accelerated,
smoother animation, advanced effects, efficient memory, and good scaling with
multiple mascots. WebGL2 is required for the renderer (the audio pipeline does
not need it).
